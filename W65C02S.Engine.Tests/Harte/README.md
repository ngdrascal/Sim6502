# SingleStepTests wdc65c02 vectors (subset)

`v1/xx.json` is a subset of the per-opcode test vectors from
https://github.com/SingleStepTests/65x02, directory `wdc65c02/v1`. The files were taken at commit
`2f6980a2d95757486c7bee24355c360e40e2a224`, and the format is unchanged. They are MIT licensed; see
`LICENSE`.

`HarteConformanceTests` runs them. Each case gives the initial registers and RAM, the final registers
and RAM, and every bus cycle as `[address, data, "read"|"write"]`.

## Subset

Each upstream file has 10,000 cases (about 4.7 MB). `scripts/HarteSubset.cs` keeps:
- up to 2 cases for each distinct signature: cycle count, decimal flag, and zero page pointer wrap
  (a read of `$00FF` followed by a read of `$0000`). Page cross, branch taken, decimal penalty and
  pointer wrap cases are kept whenever the opcode has them.
- 12 more cases chosen at random with a fixed seed.

That gives 16-28 cases per opcode and 4,501 in total. To regenerate or change the selection:

```
dotnet run scripts/HarteSubset.cs -- <cacheDir>
```

The first run downloads about 1 GB into `cacheDir`.

Upstream has no cases for `CB` (WAI) or `DB` (STP).

The vectors were generated by an emulator, not captured from hardware. Where they disagree with the
WDC datasheet, the test's opt-out list records the deviation.
